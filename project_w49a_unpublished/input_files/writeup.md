# A Tiered, Archive-Audited Kinematic-Degeneracy Study of Hypercompact HII Regions in W49N

## Abstract

Hypercompact HII (HC HII) regions in W49N show kinematic signatures that prior VLA 7 mm and ALMA 1.2 mm/H29α observations have been unable to unambiguously classify as rotating disks, expanding shells, or biconical outflows. This thesis addresses that ambiguity using only already-public archival data, remaining fully independent of the proprietary, unexecuted 2024.1.00717.S Band 9 observations. Because the thesis's viability depends on assumptions about the availability and calibration level of these older datasets, a time-boxed, four-week archive audit (Phase 0) is built in as a graded milestone, routing the project down one of three pre-defined tracks: direct use of existing calibrated images (Track A), routine `tclean` imaging from existing calibration tables (Track B, ~1–2 weeks), or a fully archival reanalysis of already-published De Pree et al. figures and measurements (Track C). Whichever track applies, the student extracts an H29α position–velocity (PV) diagram and continuum emission-measure profile for the target source(s) and fits three analytic kinematic templates via chi-square/AIC model comparison. If the PV diagrams are resolution-limited — an outcome the source proposal itself anticipates — the deliverable shifts to a Monte Carlo requirements analysis quantifying the resolution/SNR needed to discriminate the models. Success is defined as either a statistically grounded disk/shell/outflow verdict, or a rigorous quantification of why current data cannot yet resolve the question — both are bounded, single-student-scope outcomes achievable with standard CASA/analytic/Monte Carlo tools.

## Work Plan

**Phase 0 — Archive audit (Weeks 1–4, hard deadline).** Query the NRAO VLA Science Data Archive and ALMA Science Archive for W49A/W49N pointings (VLA Ka-band ~43 GHz; ALMA Band 6 ~231.9 GHz H29α), filtering by relevant PIs (De Pree, Wilner, Tobin) and known HC HII source coordinates. Cross-check candidate project codes against De Pree et al. 2024 (arXiv:2404.02250) to confirm which dataset the thesis's cited "prior ambiguous" observations actually refer to. Determine product level (calibrated images vs. visibilities only) and public release status for each candidate. Assign the thesis to Track A, B, or C accordingly, and document project codes, release dates, and the track decision as a standalone "reproducibility ledger" section of the final thesis. *Key output: audit table + track assignment.*

**Phase 1 — Kinematic extraction (Weeks 5–10).** From the continuum maps (7 mm and/or 1.2 mm), extract radial/elongation-axis brightness-temperature profiles (CASA `imstat`/`imval` or astropy+photutils) and convert to emission measure to reproduce De Pree et al.'s opacity diagnostics. From the ALMA H29α cube, extract PV diagrams along the continuum elongation axis using CASA `impv`, fitting line centroid velocity vs. position (Gaussian-per-channel or `bettermoments`/`curve_fit`). Record synthesized beam and per-channel RMS noise for both datasets. *Key outputs: emission-measure profile plot; PV diagram with velocity-vs-offset curve and uncertainties.*

**Phase 2 — Kinematic model comparison (Weeks 10–16).** Construct three analytic forward models — rotating disk (power-law rotation curve), expanding shell (radial expansion), biconical outflow (conical velocity field) — each parameterized by inclination, characteristic velocity/radius, and position angle. Grid-search or MCMC (`emcee`) fit each to the observed PV diagram, beam- and channel-convolved, weighted by per-channel noise. Compare via chi-square, AIC, and BIC, correcting for differing free-parameter counts. *Key outputs: three best-fit PV model overlays; ΔAIC/ΔBIC comparison table; posterior corner plots if MCMC used.*

**Phase 3 — Resolution/SNR fallback (Weeks 12–18, may run parallel to Phase 2).** If the beam covers only a few resolution elements across the source, inject synthetic disk/shell/outflow signals at the real beam size and noise level (CASA `simobserve`/`simanalyze` or equivalent Python injection), and re-run the Phase 2 pipeline on synthetic data to determine the resolution/SNR threshold at which the true model is recovered at stated confidence (e.g., ΔAIC > 10 in ≥90% of trials). *Key output: quantitative resolution/SNR requirements curve.*

**Tools:** CASA (imaging, PV extraction), Python (numpy, scipy, astropy, emcee, matplotlib), NRAO/ALMA archive interfaces. No new observations or proprietary data at any stage.
