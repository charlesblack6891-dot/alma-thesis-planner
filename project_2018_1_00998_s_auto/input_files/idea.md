**Title:** Spatially Resolving CO(2–1) Absorption Toward PKS1740−517: One Absorber or Two?

**Idea:** Using the calibrated long-baseline (0.034″) Band 4 measurement set and QA2 cube/continuum products for project 2018.1.00998.S, the primary workflow is: (1) image the 145–149 GHz continuum windows in CASA starting from the QA2 continuum image, treating the number and shape of continuum components (single core vs. resolved core+lobe or double nucleus) as an open empirical outcome of this imaging step, not an assumed result — the PI's framing ("one or both source components") states the question, not the answer; (2) since phase decorrelation on 0.034″ baselines is the expected failure mode, apply phase self-calibration on the bright continuum core as the first-line fix, iterating a few rounds of phase-only self-cal; pre-register a concrete go/no-go criterion before starting (e.g., "accept a self-cal round only if it improves image dynamic range by ≥X% and per-antenna solutions converge with SNR ≥3 over the chosen solution interval; stop after 3 rounds or first round that fails this test") so that a marginal, partially-converged map has a defined disposition rather than being judged ex post; (3) only if self-cal fails this pre-registered test, fall back to modest uv-tapering as a secondary, explicitly lower-priority contingency. Fit the best-achievable continuum map with `imfit` to identify discrete components; if the source does not resolve into distinct components, proceed with a single-aperture analysis as the base-case outcome, not a failure.

Then image the 159.0–160.9 GHz CO(2–1) window and extract absorption spectra against each identified continuum component (or the single aperture), using the 146–149 GHz continuum fit to normalize absorption depth. Measure line depth, centroid velocity, and FWHM via Gaussian fitting at native 1.84 km/s resolution where S/N permits, spectrally binning to a few km/s as a documented fallback for low-S/N components. Compare centroid velocities, depths, and profile shapes across components to test single foreground screen (same velocity/depth everywhere) versus spatially distinct absorbers (velocity offsets, or absorption on only one component), reporting the comparison qualitatively (e.g., "components A and B differ in centroid velocity by X km/s, consistent with distinct absorbing gas" or "velocities and depths agree within uncertainty, consistent with a single foreground screen") rather than fitting competing kinematic models, since a handful of resolvable spatial components cannot support real model discrimination. If the source is unresolved or shows a single coherent absorber, report this as a valid, bounded null result at the achieved resolution.

All work uses only the pipeline-calibrated MS and QA2 products already in the archive for this project, re-imaged in CASA — no new observations, no external catalogs, and no data beyond what is described.

This is scoped for one student in a semester–year: standard CASA continuum imaging with a pre-registered self-cal success criterion (tapering only as a brief secondary contingency), `imfit`-based component identification treated as an open empirical question with a single-aperture fallback if unresolved, spectral extraction and Gaussian fitting at a handful of discrete sky positions, and a qualitative velocity/depth-offset comparison whose outcome is well-defined and reportable regardless of how many components the source resolves into.
