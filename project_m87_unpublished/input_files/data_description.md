Target: M87 (Virgo A), a giant elliptical galaxy at the center of the Virgo Cluster,
distance 16.8 Mpc, hosting a supermassive black hole of mass 6.5 +/- 0.7 x 10^9 Msun --
the same black hole whose shadow was directly imaged by the Event Horizon Telescope
(EHT) in the widely-known 2019 results. M87 also hosts a well-studied relativistic jet
extending to kiloparsec scales.

ALMA observations: project code 2025.1.00830.V (PI: Chan), Band 6, many execution
blocks. Per the ALMA archive, this project's data-release dates span 2027-07-01 through
2027-07-14 -- more than a year in the future as of 2026-07-22, so this dataset remains
proprietary to the PI team. The ".V" project-code suffix denotes a VLBI-affiliated
program; M87 is a flagship target of Event Horizon Telescope monitoring campaigns, and
ALMA regularly participates both as part of the global VLBI array and as a
flux/polarization calibration reference during EHT epochs. ALMA's own Cycle 13
proposer's guide states VLBI observations including ALMA (EHT/GMVA-affiliated) are
expected in the March-May 2027 window, consistent with this project's release timing.

Prior ALMA coverage of this target (already public, different project codes): M87 has
substantial existing ALMA publication history unrelated to this project, including
"First polarization study of the M87 jet and active galactic nuclei at submillimeter
wavelengths with ALMA" (A&A 699, A265, July 2025; Band 7 at 345 GHz, reporting linear
polarization fractions of 1-17% and rotation-measure gradients suggesting a helical
jet magnetic field), the VAPOLA multi-year, multi-band AGN/Sgr A* polarization survey,
and multiple broadband multiwavelength papers tied to the 2017/2018 EHT observing
campaigns. None of these correspond to this specific project code.
