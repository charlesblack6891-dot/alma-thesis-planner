**Title: Quantitative Model Comparison of Magnetic-Field Geometries in the M87 Jet Using Published ALMA Polarization Values**

*Context:* The assigned dataset (ALMA project 2025.1.00830.V, PI Chan) remains proprietary until mid-2027, and its scientific purpose is only speculatively inferred from its VLBI-affiliated project-code suffix and M87 target — no proposal abstract confirms it. It cannot anchor a thesis. The data description does name two already-public ALMA-derived resources bearing on the same physical question the proprietary project's inferred goal touches on (the state and structure of the magnetic field in M87's compact core/jet-base region during EHT-support epochs): A&A 699, A265 (2025), which reports Band 7 (345 GHz) linear polarization fractions (1–17%) and a rotation-measure (RM) gradient along the M87 jet interpreted as evidence of a helical magnetic field, and the VAPOLA multi-epoch, multi-band ALMA AGN polarization survey. This thesis uses only the numerical results already published in these two sources — polarization fractions, EVPAs, and RM values as reported in their tables/figures — and does not assume access to any raw or calibrated visibility/image data beyond what is stated to be published.

*Proposed thesis project:* Compile the published per-position polarization fraction, EVPA, and RM (or RM-gradient) measurements along the M87 jet from A&A 699, A265, digitizing values directly from the paper's tables and figures (standard, bounded plot-digitization work). Using these compiled values, fit a small set of analytic toy magnetic-field models — helical, purely toroidal, purely poloidal, and a null/tangled-field baseline — each of which predicts a specific EVPA and RM behavior as a function of distance/position angle along the jet, using standard closed-form jet-polarization formulas from the literature on relativistic jet polarimetry. Perform a simple goodness-of-fit / model-comparison analysis (e.g., chi-square and/or AIC/BIC across the candidate models) to quantify how strongly the published data favor the helical interpretation over the simpler alternatives — a test the original paper's qualitative RM-gradient argument does not itself perform. As a secondary, explicitly small-N consistency check, pull any publicly reported VAPOLA core-region polarization/EVPA values at other epochs/bands and check whether the sign and rough magnitude of the core polarization state is compatible with the same field-geometry sign convention favored by the jet-scale fit, flagged clearly as a supplementary check rather than a full variability study.

*Scope:* All measurements used are values already published and explicitly named in the sourcing material (A&A 699 A265 tables/figures; VAPOLA reported values) — no raw visibility calibration, imaging, or RM-synthesis pipeline work, and no assumption of archive access to underlying image products. The core analytical work — digitizing published values, implementing a handful of standard analytic polarization-model formulas, and running a model-comparison statistic — is bounded, well-precedented in jet-polarimetry literature, and squarely within reach of one student in a semester-to-year thesis.
