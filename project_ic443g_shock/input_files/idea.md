**Quantitative Shock-Model Fitting to Archival Multi-Transition Line Data Toward IC443G**

This thesis drops the proprietary ALMA dataset (2025.1.00086.S) entirely — it is locked until 2027-07-10, more than a year past any thesis deadline, and its line content, resolution, and sensitivity are unknown, so no defensible up-front science question can be built on it. Instead, the thesis uses only already-public, already-described data: the published multi-transition single-dish line measurements toward clump G (CO, HCO+, HCN, CN, SiO, CS, SO, H2CO from Turner et al. 1992 and related literature) and the published broad-line [CI] detection, all of which exist now as tabulated intensities/line ratios in the literature, not as data the student needs special access to acquire.

Scope of work:
1. Compile a homogeneous table of published line intensities, velocities, and linewidths toward clump G across all reported species/transitions from Turner et al. 1992 and any other cited single-dish studies of this position.
2. Use a non-LTE excitation code (RADEX or equivalent, publicly available) to derive densities and column densities consistent with the observed line ratios for each species, under both single- and two-component (broad/narrow) velocity decompositions already reported in the literature.
3. Use a public parametrized shock-model grid (e.g., Paris-Durham C-shock/J-shock code outputs, or published grids such as Flower & Pineau des Forêts) to fit the derived column densities and abundance ratios (e.g., SiO/CO, HCO+/CO, CN/HCN) against shock-speed/pre-shock-density/magnetic-field parameter space for both C-type and J-type shock families.
4. Quantitatively test the qualitative literature claim that clump G requires a *mixture* of J-type and C-type shocks: fit single-shock-type models first, evaluate residuals/goodness-of-fit species-by-species, then fit a two-component (J+C) mixture model and compare statistically (e.g., via chi-square or Bayesian model comparison) whether the mixture is required by the data or if a single shock type with a range of parameters suffices.
5. Present best-fit shock parameters (speed, pre-shock density, age indicators) for clump G, framed as a refinement/quantitative test of the existing qualitative picture, not a new detection.

Deliverable: a compiled archival line-ratio dataset for clump G, a set of RADEX excitation solutions, and a shock-model parameter fit (single vs. mixed shock-type) with a quantitative goodness-of-fit comparison — a self-contained, one-semester-to-one-year thesis using only literature-derived data and standard, freely available modeling codes (RADEX, a public shock-model grid), with no dependence on proprietary or unreleased data and no new observations required.
