**Title:** Testing Spatio-Chemical Differentiation in the HH 212 Outflow at ACA Resolution: A Coarse Lobe-Scale Line-Ratio and Velocity-Structure Comparison Between Jet and Wall Tracers

**Target:** HH 212 only, using the six ACA member OUS tunings covering this source (`Xf93`, `Xfa6`, `Xfb9`, `Xfcc`, `Xfdf`, `Xff2`), spanning ~292–361 GHz in Band 7, with pipeline-calibrated QA2 cubes already in the archive. This thesis deliberately narrows the survey's original seven-source, cross-environment comparison to a single well-studied outflow; it demonstrates the jet-vs-wall differentiation method on one source rather than testing how differentiation depends on outflow age/velocity/environment across the full sample. That trade is made explicitly for tractability.

**Idea:** As a first go/no-go step, the student checks HH 212's known bipolar lobe extent against the ACA primary beam (~30″ at these frequencies, single-pointing, no mosaic) to confirm both lobes are adequately covered before committing to the full analysis; if one lobe falls outside the beam, the analysis is restricted to the covered lobe and this is reported as a limitation.

Before imaging, the student runs an explicit Splatalogue verification pass on the four proposed lines — SiO 8–7 (347.331 GHz), ¹²CO 3–2 (345.796 GHz), SO 8₈–7₇ (344.311 GHz), and CH₃OH 7₀–6₀ A⁺ (338.409 GHz) — checking each against the full Splatalogue line list within ±the channel width of its rest frequency, since the data description's own line list is annotated as "generated from general knowledge, verify before imaging." Any line found to have a plausible blended contaminant at HH 212's velocity range is either dropped or flagged, and the tracer set is finalized only after this check, not assumed from the annotation alone.

The student then images (or works from the archived cubes for) these four confirmed transitions, producing moment 0/1/2 maps, and extracts integrated spectra in beam-sized (or larger) apertures stepped along the known jet axis out to the lobe edges (bounded by the FOV check above). Given the ~3.2–4″ beam and ~30″ usable field, the student should expect only ~3–4 independent apertures per lobe; the analysis is explicitly framed as a coarse gradient check across a handful of resolution elements, not a fitted spatial profile, and the writeup states this sampling limitation up front rather than presenting the result as a resolved trend.

For each aperture, the student computes (1) line-ratio comparisons (SiO/CH₃OH, CO/SO) across the ~3–4 positions per lobe, testing whether jet tracers stay centrally peaked while wall tracers show a flatter or offset distribution, and (2) per-aperture velocity structure — line width, peak velocity, high-velocity wing strength — comparing SiO/CO against SO/CH₃OH at matched positions, since ~0.94–1.1 km/s spectral resolution can separate broad high-velocity jet components from narrower wall/ambient components even when spatially blended within one beam. If a chosen transition turns out to be too weak in a given aperture (checked via quick pre-imaging spectral inspection), that aperture is dropped from the ratio analysis rather than substituted.

The final deliverable is a lobe-averaged, coarse-sampled chemical/kinematic differentiation comparison for HH 212, plus an explicit beam-dilution and sparse-sampling discussion stating what scale of differentiation the ACA data can versus cannot detect. Any comparison to higher-resolution literature is included only as one or two sentences of qualitative framing, not a quantitative data input. This keeps the entire analysis — Splatalogue line verification, imaging, moment maps, aperture spectral extraction, line-ratio and velocity-structure comparison — to standard CASA workflows on a single already-calibrated dataset, with no new observations, no external catalogs, and a scope matched to one student in a thesis timeframe.
