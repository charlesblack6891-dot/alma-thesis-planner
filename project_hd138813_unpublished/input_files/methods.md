**Step 0: Literature audit and scope-defining triage (Weeks 1–3)**

Before touching any data, read the ARKS survey-overview paper and all nine companion papers in the A&A 705, A195 series (20 January 2026), specifically extracting every statement made about HD 138813: the achieved continuum resolution for this source, any reported ring geometry (inclination, position angle, radial location of ring peak/edges), any mention of CO or joint dust-gas analysis for this system, and whether a per-target radial profile or gas-to-dust ratio was already published. Tabulate this in a short reading log with page/figure citations. Cross-reference against Lieman-Sifry et al. (2016) and Hales et al. (2019) to confirm which quantities (dust mass, CO mass, ring radii, disk geometry) are already established versus only qualitatively stated.

This triage produces a binary fork that must be resolved before writing any analysis code:
- If ARKS already published a single-target quantitative radial dust-gas comparison for HD 138813, the thesis pivots to an independent re-derivation of that comparison from the public data products, with the explicit deliverable of a side-by-side numerical comparison (profile shape, ring radii, gas-to-dust ratio) against the published ARKS values, including a discussion of where methodology differences (e.g., visibility-domain fitting vs. their pipeline) could explain any discrepancy.
- If no such single-target quantitative comparison exists in the ARKS papers, proceed as an original analysis per Steps 1–5 below.

Document this decision and its justification in the thesis methods chapter itself, since it is the scientific gap statement the rest of the thesis is built on.

**Step 1: Data acquisition and inventory (Week 3–4)**

Query the ALMA Science Archive for project code 2022.1.00338.L, source HD 138813, Band 7. Determine concretely what is retrievable: calibrated measurement sets (visibilities) if delivered as part of the ARKS QA2 products, or only the pipeline-produced FITS continuum image/cube if visibilities are not separately staged. Do the same for the Hales et al. (2019) CO data (which ALMA project code, what data products — visibilities, CLEANed cube, or only published moment maps in the paper's supplementary material). Record exactly which tier of product exists for each of the two tracers (dust continuum, CO line) in a data-provenance table, since this table dictates which of Step 3's two analysis paths is used for each tracer. At no point download, request, or reference anything from project code 2025.1.00062.S — confirm this exclusion explicitly in a data-management note, since that dataset's release date (2027) postdates the thesis.

**Step 2: Calibration and imaging reproduction, where visibilities exist (Weeks 4–7)**

For any tracer where calibrated visibilities are retrievable, reproduce a clean, well-characterized image domain product using CASA (matching or updating the ARKS/Hales pipeline scripts where available): apply the delivered calibration, run `tclean` with a chosen weighting scheme (start with Briggs robust = 0.5 as a compromise between resolution and sensitivity, matching typical ARKS choices), and iterate over robust parameter only if signal-to-noise in the image domain is a limiting factor for the subsequent profile fit. Fit the source geometry (inclination, position angle, phase center) using an elliptical Gaussian or ring model fit to the CLEANed image, and cross-check against any geometry quoted in the literature (Lieman-Sifry 2016 quotes disk PA/inclination) as a sanity check on the reproduction, not as a fixed input.

**Step 3: Radial profile extraction — resolution-matched dual path (Weeks 7–10)**

This is the methodological core of the thesis and must be applied symmetrically to both tracers so the final comparison is not an artifact of mismatched techniques.

*Path A (visibility-domain, used if calibrated visibilities exist for a tracer):* Use `frank` (Frankenstein) to fit a non-parametric radial brightness profile directly to the deprojected visibilities, using the geometry fit from Step 2 as the deprojection input. Independently fit `frank` profiles for the continuum and, separately, for the CO integrated intensity (zeroth-moment) visibilities if line visibilities are available. Do not force a shared geometry across tracers at this stage — fit inclination/PA independently for dust and gas and record both, since a geometry mismatch is itself a diagnostic (misaligned dust and gas would suggest a different physical origin, e.g. an exocometary gas source rather than primordial disk gas). Propagate `frank`'s output radial brightness uncertainties (from its Gaussian-process posterior) into the profile.

*Path B (image-domain, used for any tracer where only released images/moment maps are retrievable):* Deproject the CLEANed image (or moment-0 map) using the geometry from Step 2, then compute an azimuthally-averaged radial brightness profile in concentric elliptical annuli of width matched to roughly one synthesized beam. Propagate uncertainty per annulus from the map's local rms noise divided by the square root of the number of independent beams per annulus.

Critically: if one tracer uses Path A and the other Path B, additionally compute the Path-B (image-domain) profile for the Path-A tracer as well, so a like-for-like image-domain comparison is always available alongside the higher-fidelity visibility-domain one — this avoids conflating a real physical dust-gas difference with a methodological difference between fitting domains.

**Step 4: Geometry consistency check and common physical axis (Week 10–11)**

Compare the independently fit dust and CO geometries (inclination, PA, center offset) with their formal uncertainties. Quantify agreement (e.g., in units of combined sigma). If they agree within uncertainty, adopt a single common geometry (inverse-variance weighted average) to convert both profiles to a shared physical radius axis in au, using the fixed distance of 130.3 pc. If they disagree significantly, retain separate geometries but still report both profiles on a common physical (au) radius axis by deprojecting each independently before overlay — and flag the disagreement itself as a result worth discussing quantitatively rather than averaging it away.

**Step 5: Quantitative dust-gas comparison and mass cross-check (Weeks 11–14)**

With both profiles on the same physical radius grid, compute a radius-dependent ratio profile (CO flux or surface density divided by dust continuum flux or surface density), propagating uncertainty from both profiles in quadrature at each radius bin. Fit or characterize the ratio profile's radial trend using a simple parametric description (e.g., linear or broken power-law in radius) plus a null hypothesis test (constant ratio, i.e., no radial trend) using a chi-squared or likelihood-ratio comparison between the constant and trending models, so that "no detectable radial trend within current sensitivity" is treated as a reportable, valid outcome rather than a failure.

Separately, integrate the fitted continuum brightness profile to derive a total millimeter flux, and convert to dust mass using the standard optically-thin isothermal assumption (adopting the same dust opacity and temperature assumptions as Lieman-Sifry et al. 2016 for direct comparability). Integrate the CO profile and convert to gas mass following the same conversion framework as Hales et al. (2019), including their assumed CO/H2 abundance ratio and excitation temperature. Compare both derived masses, with propagated uncertainties, against the literature values (0.0083 ± 0.0015 M⊕ dust; 0.0001–0.003 M⊕ CO) as an internal consistency check on the whole pipeline — a mass recovery within the literature's quoted range validates the calibration and imaging reproduction in Steps 1–2 before the radial ratio result in this step is trusted.

**Step 6: Uncertainty synthesis and thesis writeup (Weeks 14–16)**

Assemble the final results: the two individually-fit geometries and their consistency, the overlaid radial dust and gas profiles on the common au axis, the uncertainty-bounded ratio-vs-radius profile with its trend/null test result, and the mass cross-check table against literature values. Write the results as an uncertainty-bounded scientific statement (e.g., "the gas-to-dust ratio shows/does not show a statistically significant radial trend at the X-sigma level between R1 and R2 au") rather than a qualitative restatement of the disk's already-known gas/dust radial offset. If Step 0 triggered the reproducibility-check fork, include the explicit numerical side-by-side against ARKS's published values as the thesis's primary results table.
