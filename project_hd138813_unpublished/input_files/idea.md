**Title:** Quantitative Radial Dust-Gas Structure in the HD 138813 Debris Disk: A Resolution-Matched Reanalysis Using Public ALMA Data

**Data used (all already public; no proprietary access required):** the public ARKS Band 7 continuum data for HD 138813 from ALMA project 2022.1.00338.L (public following the A&A 705, A195 survey release, January 2026), whatever data products are actually retrievable for it (calibrated visibilities if released, else the survey's released FITS images); the public CO data/moment maps from Hales et al. (2019); and the published dust-ring/gas geometry and mass values from Lieman-Sifry et al. (2016) and Hales et al. (2019). The proprietary 2025.1.00062.S dataset (release 2027) is explicitly excluded and not used at any stage.

**Description:**

*Step 0 (before committing to the topic):* Before any reduction begins, the student reads the ARKS survey-overview paper and its companion papers in the A&A 705, A195 series specifically for what they report about HD 138813 — resolution achieved, any per-target substructure or radial dust-gas comparison already published. This determines the thesis's actual gap: if ARKS already published a single-target radial fit and dust-gas comparison for this system, the thesis instead targets an independent re-derivation with quantified agreement/disagreement against ARKS's published numbers (a legitimate reproducibility/consistency check); if no such single-target quantitative comparison exists (plausible, since a 24-target survey paper reports per-target results but doesn't necessarily do a deep joint dust-gas radial analysis for each one), the thesis proceeds as an original quantitative comparison for this target.

*Steps 1-4 (contingent on data granularity, checked upfront):* First confirm whether calibrated visibilities are retrievable for the ARKS continuum and for the Hales CO data. If both are available, fit each tracer's radial brightness profile in the visibility domain (`frank`/`galario`), fitting geometry (inclination, PA, disk center) independently per tracer rather than assuming a shared value. If only released images/moment maps exist for one or both tracers, fall back to azimuthally-averaged image-domain radial profiles for *both* tracers symmetrically, so the two profiles are derived by the same method and not mismatched between visibility- and image-domain approaches. Once independent geometries are obtained, check their consistency (do dust and gas agree on inclination/PA within uncertainty?) before adopting a common physical (au) axis for comparison.

*Step 5:* Overlay the resulting dust and gas radial profiles on the common axis and compute a quantitative, uncertainty-bounded gas-to-dust surface density/flux ratio as a function of radius, rather than simply restating the already-known qualitative fact that CO is concentrated interior to the dust ring. Identify whether the ratio profile shows any radial trend (e.g., enhancement near the dust ring's inner edge, a plateau, a monotonic decline) that is new information beyond the coarser discovery-era characterization. Cross-check the newly fit total dust and gas masses against the literature values (0.0083 ± 0.0015 Mearth dust; 0.0001-0.003 Mearth CO) for internal consistency, and report uncertainty-bounded conclusions (including a null result — e.g., "no radius-dependent ratio detected within current sensitivity" — as a valid outcome).

This remains tractable in one thesis timeframe: single target, two already-public tracers, standard tools (CASA, `frank`/`galario` or image-domain azimuthal averaging, error propagation for a ratio profile), and a well-defined, appropriately scoped quantitative question, with the literature/redundancy check performed first so the entire plan is not contingent on an assumption that turns out to be wrong midway through the thesis.
