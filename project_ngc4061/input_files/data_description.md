Target: NGC 4061, an early-type (lenticular) galaxy, adopted distance D = 107.2 Mpc
(H0 = 70 km/s/Mpc, Omega_m = 0.3).

ALMA observations: Band 6, four spectral windows in frequency-division mode (FDM),
centered on the redshifted 12CO(2-1) line (rest frequency 230.538 GHz). The dataset
combines two archival ALMA projects observed with the 12-m array in the C43-7 and
C43-5 configurations:

- Project code 2018.1.00397.S (PI: M. Smith)
- Project code 2019.1.00036.S (PI: D. Nguyen)

Angular resolution / sensitivity: synthesized beam approx 0.16 arcsec (continuum),
continuum rms noise sigma_cont approx 120 microJy/beam. Field of view approx 25 x 25
arcsec (approx 13 x 13 kpc at the adopted distance), set by ALMA's primary beam FWHM
(~25 arcsec) at this frequency.

Data products: Band 6 continuum image, and a 12CO(2-1) data cube with derived moment
maps (integrated intensity, velocity, velocity dispersion) tracing the galaxy's
central molecular gas disk kinematics.

Science context: this dataset is drawn from a published study (Nguyen et al. 2026,
ApJ, DOI 10.3847/1538-4357/ae771c) that used the CO(2-1) disk kinematics to
dynamically measure the mass of NGC 4061's central supermassive black hole, reporting
a result on the order of a billion solar masses.
